# Changelog

## 1.2.0 - first public release
- Generic setup for any server: the installer asks for your folder, name, address and port, and detects your time zone.
- One-line install from GitHub, plus `update.sh` (keeps your settings) and `uninstall.sh`.
- The panel shows a notice when a new version is out.
- Ready for the optional Craftlehem Pro add-on (Settings → Pro).
- Settings from earlier private versions are converted automatically.

## 1.1.x - private versions
- Config editor with mistake-checking and version history.
- Player names with rank prefixes/suffixes (e.g. `[VIP] Name [Admin]`) are recognised correctly.
- Works behind a Cloudflare Tunnel (real visitor IPs for the login lockout).
- Black and purple theme.

## 1.0.0
- Dashboard, console, players, mods, files, backups, schedule, logs, settings, users and roles, activity log.
